# Blue Gill Plant Tech Website

This project is a single-page website for Blue Gill Plant Tech, a construction company serving clients in Eswatini and South Africa.

## Project Structure

- **index.html**: The main HTML document containing the website's structure and content.
- **styles.css**: CSS file for styling the website.
- **script.js**: JavaScript file for adding interactivity to the website.
- **README.md**: Documentation for the project.

## Setup Instructions

1. Clone the repository or download the project files.
2. Open the project folder in your preferred code editor.
3. Open `index.html` in a web browser to view the website.
4. Edit `styles.css` to customize the appearance.
5. Modify `script.js` to add any interactive features as needed.
